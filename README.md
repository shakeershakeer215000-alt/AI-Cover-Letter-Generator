# Letterly AI — AI Cover Letter Generator

A responsive Next.js SaaS-style cover letter studio with server-side AI generation, demo mode, editable letters, browser-saved history, and PDF/DOCX export.

## Run locally
1. Install Node.js 20.9+.
2. Run npm install.
3. Copy .env.example to .env.local.
4. Add your server-side OPENAI_API_KEY to enable live AI (optional for demo mode).
5. Run npm run dev and open http://localhost:3000.

## Environment variables
- OPENAI_API_KEY: secret API key, server-side only.
- OPENAI_MODEL: optional model name; defaults to gpt-4o-mini.

Without an API key, choose Try demo to preview the workflow. Demo content is clearly labelled and is not generated by a live AI model. For real AI writing, configure the key in Vercel → Project Settings → Environment Variables and redeploy.

## Features
- Responsive landing page and cover-letter studio
- Personal, job, education, skills, and experience inputs
- Writing tone, length, and seven template choices
- Server-side OpenAI-compatible chat completions integration
- Fact-grounded prompts that prohibit invented qualifications
- Editable preview, copy, save, PDF and DOCX export
- Browser-local history, dark/light mode, and quick rewrite actions
- About, Privacy Policy, and Terms pages

## Deploy to Vercel
The Vercel project is already connected to this GitHub repository. Pushes to main trigger a deployment. Add OPENAI_API_KEY and optionally OPENAI_MODEL in the Vercel project environment variables before expecting live AI generation.

## Current scope and limitations
Saved letters use browser localStorage on the current device. Account authentication, Google sign-in, cloud sync, and Supabase/Firebase persistence are not enabled in this release. The template selector controls the prompt context; it does not yet provide separately typeset document themes. Add rate limiting and abuse monitoring before opening generation to large public traffic.

## Security
The AI key is read only by the API route and is never sent to client-side code. Never commit real API keys or .env.local.
